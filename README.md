# Fedresurs AMSROS Parser

## Описание
Консольное Spring Boot приложение для получения и парсинга данных
с официального сайта Fedresurs.

Приложение выполняет HTTP-запросы к открытому API Fedresurs,
обрабатывает JSON-ответ и преобразует данные в Java-объекты.


 Принцип работы
1. При запуске приложения выполняется HTTP GET запрос к API Fedresurs  
   `/backend/amsros?limit=100&offset=0`
2. Ответ содержит:
   - `pageData` — список объектов
   - `total` — общее количество записей
3. Первый запрос используется для получения общего количества записей
4. Далее данные загружаются постранично с использованием параметров
   `limit` и `offset`
5. Все полученные объекты собираются в единый список
6. Результат выводится в консоль
