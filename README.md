# Fedresurs AMSROS Parser

## Описание
Консольное Spring Boot приложение для получения и парсинга данных
с официального сайта Fedresurs.

Приложение выполняет HTTP-запросы к открытому API Fedresurs,
обрабатывает JSON-ответ и преобразует данные в Java-объекты.


 Принцип работы
1. При запуске приложения выполняется HTTP GET запрос к API Fedresurs  
   `/backend/amsros?limit=100&offset=0`
2. Ответ содержит:
   - `pageData` — список объектов
   - `total` — общее количество записей
3. Первый запрос используется для получения общего количества записей
4. Далее данные загружаются постранично с использованием параметров
   `limit` и `offset`
5. Все полученные объекты собираются в единый список
6. Результат выводится в консоль


Архитектура проекта -
1. FedresursClient - Компонент для выполнения HTTP-запросов.
Используется WebClient (Spring WebFlux),
что делает решение более современным по сравнению с RestTemplate. Метод loadPage отвечает за загрузку одной страницы данных.

2. ParserApplication - Реализует CommandLineRunner.  Отвечает за:
   1. запуск логики после старта приложения
   2. постраничную загрузку данных 
   3. объединение результатов
   4. вызов Excel-экспорта

3. ExcelWriter - Отвечает за:
   1. создание Workbook
   2. формирование листа
   3. создание заголовков
   4. запись строк
   5. автоширину колонок
   6. сохранение файла
   7. Используется Apache POI.
